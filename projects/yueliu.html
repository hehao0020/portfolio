桌面工具 · Windows / macOS 本地版

阅流 · 公众号创作台

把运营经验沉淀为可确认的创作流程

公众号两个月涨粉 1500 的实践在前，阅流工具形成在后。产品围绕选题、写作、审稿和排版设计，强调关键环节由作者确认。

先有运营实践，再有工具

我曾运营公众号，两个月涨粉 1500。选题、资料、观点、成稿和排版之间有大量需要来回判断的环节。后来我把这段工作经验整理为“阅流”创作台，希望让成熟的创作步骤可以复用，同时保留作者的判断。

1500 粉丝的增长发生在阅流形成之前，是需求背景和个人运营经历，不能作为工具带来的增长成果。

关键步骤由人确认

输入主题与读者确定选题组织大纲协作写稿核验审稿排版导出

AI 可以帮助组织素材和初稿，但选题、大纲、审稿各有可编辑的确认点。作者可以修改结果、调整流程，再进入下一步。这样把“生成”放进创作过程，而不是一次性吐出一篇文章。

正文编辑与排版分开：同一篇文章可试用 36 套整篇模板，查看手机预览，复制带格式正文，或导出 Markdown / HTML，再由作者到公众号后台检查和发布。

从经验到可复用工作流

本机 README 记录 Windows 与 macOS 桌面版本、文章库、模板排版和阅读复盘。阅读、分享、涨粉与成本可由用户手动记录，供日后复盘，不会自动声称由工具带来增长。

产品状态与验证边界

目前能展示的是创作流程和可用的本地工具。真实模型服务的可用性取决于用户配置及网络环境；网页接入方式也会受登录与页面结构变化影响。后续应记录从素材到可用稿件的时间、修改次数和采用率，再评估工具是否真正提升创作效率。
